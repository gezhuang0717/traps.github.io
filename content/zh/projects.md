## MASSPASS——芬兰科学院研究员项目（负责人），2023–2027
在 IGISOL 和 RIKEN 测量直至 ¹⁰⁰Sn 的 *N* = *Z* 奇特核及其附近核素的质量，服务于原子核物理和核天体物理研究。芬兰研究理事会资助。[项目主页](https://www.jyu.fi/en/projects/mass-measurements-of-exotic-nz-nuclei-up-to-100sn-and-the-vicinity-for-nuclear-physics-and-nuclear)

**团队：** 葛壮（负责人）；前博士后 B. Kootte 博士；博士研究生 M. Winter。

## 用于确定中微子质量的低 Q 值衰变
利用 JYFLTRAP 彭宁阱测量 Q 值，寻找并验证超低 Q 值 β⁻ 衰变和电子俘获跃迁。

**团队：** 葛壮（发言人）；前博士后 M. de Oliveira Ramalho 博士（理论）；博士研究生 M. Winter。

## 多次反射飞行时间（MR-TOF）质谱
MR-TOF 谱仪的设计、离子光学模拟和数据分析流程。

## RFQ 冷却聚束器与束流准备
射频四极（RFQ）冷却聚束器的离子光学设计，为实验提供冷却、聚束的放射性束流。

## 储存环探测器
为 RIKEN Rare-RI Ring 研制的定时与位置灵敏 MCP 探测器，以及 HIAF 探测器方案。

## 科研软件
用 Python 编写的彭宁阱粒子模拟、MR-TOF 刻度和二维 MCP 位置刻度工具。

## 项目的科学背景

**MASSPASS。** 沿 *N* = *Z* 线的质量给出双质子和双中子分离能以及结合能中的对关联和 Wigner 贡献，并检验趋近 ¹⁰⁰Sn 的壳演化。对 rp 过程，质量提供决定 Sn–Sb–Te 循环延伸范围的反应 *Q* 值。这些核素用 IGISOL 技术产生，经质量分离，在 RFQ 中冷却聚束，再用 JYFLTRAP 和 MR-TOF 谱仪测量。

**低 *Q* 值衰变。** 目标是为未来直接测量中微子质量的实验提供可靠候选者清单：对每个跃迁以几百 eV 或更好的精度测量衰变能，并用核结构数据检验激发态能量。

**MR-TOF 质谱。** 工作包括离子光学模拟（SIMION）、用参考离子进行飞行时间标定（*m*/*q* ∝ (*t* − *t*<sub>0</sub>)<sup>2</sup>）、峰形拟合，以及把频率比或时间比转换为原子质量和质量过剩。

**RFQ 冷却聚束器。** 在充氦的射频四极场中，射频场在径向约束离子，碰撞使其冷却；微弱的轴向直流梯度把离子引到势阱中，再释放出短而低发射度的束团以便注入离子阱。

**储存环探测器。** 在等时性质谱中，储存离子的回旋周期取决于质荷比；储存环运行在转变能量时可抵消对速度的一阶依赖。带微通道板的薄膜计时探测器以亚纳秒分辨率测量回旋周期。

**科研软件。** Python 程序积分离子在彭宁阱中的运动方程（含离子间库仑相互作用），用参考离子标定 MR-TOF 谱，并修正二维 MCP 探测器的位置畸变。
